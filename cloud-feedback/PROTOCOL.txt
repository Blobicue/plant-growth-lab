Local signal: narrow implementation resolution
Sample connected developing root proposals after maintenance/reserve collection
and ordinary proposal preparation, before any construction payment. Freeze inputs
across plants. D=1 iff front N<.000108, C>=.0018 and W>=.00054. Otherwise D=0.
The source is the current paid front, not an unbuilt path or a whole-plant pool.
Each signal is tagged with source proposal ID, source front, emission tick, unchanged
proposal deadline, value and traversed paid-edge path. At the source it is visible
immediately. A double-buffered wave moves exactly one active connected edge per
hour; it cannot revisit a vertex. Each node selects the newest emission per source
proposal among waves received THIS hour. It never retains an old received signal
as an indefinite cache; the forwarding buffer and local inhibition are separate.
Newer D=0 takes precedence over older D=1 for the same source. Different source
proposals combine by Boolean OR. Old-source-front waves can arrive after a front
moves: this is intentional delayed information, not knowledge of its present state.

Use current local endpoints to reject propagation across a dead/disconnected edge.
A severed edge does not cause an instantaneous remote purge: already downstream
waves can finish traveling, constrained by no revisits and the ORIGINAL deadline.
A proposal's failure/expiry stops source emission; expiry is also carried as a lease
and checked at every receiver (tick>=deadline invalid). This clarifies DESIGN's
'invalidate messages through severed edges' without introducing a global oracle.
Late or stale signals are a stated tradeoff, logged explicitly. No signal crosses
between plants. Propagation occurs once/hour even if there are three material passes.

Only optional stem/leaf construction at a receiving front is withheld. Root payment,
transport, uptake, maintenance, repair, reserve protection/collection, creation and
14h proposal expiry remain the original rules. Never earmark or withdraw resources.
